Processing stages

01
Ingestion

Read synthetic or Kafka events with source mode environment variable.

02
ETL & Event time

Parse JSON, reject invalid records, assign 15-second out-of-order watermarks.

03
Stateful risk engine

Per-account history, 5-minute rolling velocity and spend, device and country signals.

04
Decision delivery

Score 0–100 and emit ALLOW / REVIEW / BLOCK candidate decisions.
